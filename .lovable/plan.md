# خطة التنفيذ

## 1. معرض الصور في بطاقة العرض (الصفحة الرئيسية)
معرض الأسهم والنقاط موجود بالفعل داخل `PropertyCard`. سأضيف:
- دعم **السحب باللمس/الماوس** (swipe) لتغيير الصورة داخل البطاقة بسلاسة دون فتح صفحة التفاصيل.
- انتقال أنعم (fade/slide) بين الصور.

## 2. قاعدة البيانات (migration واحدة)
- توسعة نوع الأدوار: إضافة `staff` إلى `app_role`.
- جدول `staff_permissions` (user_id, permission key) — صلاحيات مستقلة لكل موظف.
- جدول `activity_log` (user_id, actor_email, action, entity, entity_label, details, created_at) لتسجيل كل العمليات.
- إضافة أعمدة محتوى قانوني إلى `site_settings`: `terms_ar`, `terms_en`, `privacy_ar`, `privacy_en`.
- دوال أمان: `has_any_staff_access()` للتحقق من دخول الموظف، وسياسات RLS مناسبة (المدير يرى كل شيء، الموظف حسب صلاحياته).

## 3. دوال الخادم (server functions، صلاحية المدير فقط)
- `createStaff` — إنشاء حساب موظف (بريد، اسم، كلمة مرور) عبر Admin API + منح دور `staff` + حفظ الصلاحيات المختارة.
- `listStaff` — عرض الموظفين وصلاحياتهم.
- `updateStaffPermissions` / `deleteStaff`.
كلها محمية بـ `requireSupabaseAuth` + فحص `has_role(admin)`.

## 4. لوحة التحكم — أقسام جديدة في الشريط الجانبي
- **الموظفون**: نموذج إضافة موظف (البريد، الاسم، كلمة المرور، قائمة صلاحيات قابلة للتفعيل/الإلغاء)، وقائمة بالموظفين الحاليين مع تعديل/حذف.
- **سجل النشاط**: عرض جميع العمليات (إضافة/تعديل/حذف) مرتبطة بالموظف ووقتها — للمدير فقط.
- **الإعدادات العامة**: قسم جديد لتعبئة نص **شروط الاستخدام** و**سياسة الخصوصية** (عربي/إنجليزي) يحفظ في قاعدة البيانات.

نظام الصلاحيات سيقيّد ظهور الأقسام للموظف الفرعي: الموظف يرى فقط الأقسام المصرّح له بها؛ المدير يرى كل شيء بما فيها الموظفين وسجل النشاط.

قائمة الصلاحيات المتاحة:
```text
properties (إدارة العروض) · taxonomy · geo · requests · interests · settings
```

## 5. تسجيل النشاط
عند إنشاء/تعديل/حذف عرض أو تغيير إعدادات، تُكتب سطر في `activity_log` يحمل هوية المنفّذ.

## 6. التذييل + صفحات قانونية
- إنشاء مسارين عامين: `/terms` و`/privacy` يعرضان المحتوى من قاعدة البيانات (فارغ = رسالة "لا يوجد محتوى بعد").
- إضافة رابطي **شروط الاستخدام** و**سياسة الخصوصية** في التذييل.

## ملاحظات تقنية
- بوابة الدخول للوحة التحكم ستقبل المدير أو موظفًا لديه أي صلاحية.
- الصلاحيات تُفرض في الواجهة وأيضًا عبر RLS في الخادم.
